# Give every homepage feature an illustrated chapter, guided by the Sage

The old homepage compressed its main features into seven image buttons and tucked newer Commander tools into the stats strip. This UI-only change gives all fourteen feature routes a named, illustrated area and a clear existing action.

The approved design uses continuous ivory and emerald canvases, softly integrated fantasy scenes, large editorial serif typography, chamfered primary controls and lighter secondary links. A top menu and accessible mobile dialog provide fast navigation. Restrained hover/press feedback respects reduced-motion and the existing motion preference. The Sage's warm wizard voice explains every feature without promising unsupported functionality.

Deck, bulk and notification counts still come from existing state. Account gating, routes, handlers, persistence, scanner and recommendation engines are unchanged. No backend, authentication, schema, API, CI workflow or subpage implementation changes. Four original fantasy illustrations fill missing tool scenes; other scenes reuse existing Deck Sage art. System fonts avoid proprietary font redistribution.

Validation: 13 homepage checks, 5 interaction checks, 17 existing source/account regression scripts, and 9 preserved feature browser suites. Typecheck, the account bundle and local production webpack export passed. Installed Windows Turbopack cannot start its CSS worker; the unchanged normal Linux build and Pages deployment will be verified after merge. Each image is under 350KB; the 2.36MB feature-art set is lazy loaded and the hero is 287KB. Browser tests use mock accounts and block external writes.

The user approved the rendered layout and controls, then explicitly authorized the final Sage copy pass and publication. This release preserves that approved design.
